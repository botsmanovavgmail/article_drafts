# Проверка сайта: аудит скорости, безопасности и SEO

Сайт может выглядеть нормально и при этом терять трафик из-за медленной загрузки, ошибок индексации или проблем с безопасностью. Проверка сайта — это быстрый способ увидеть, что не так. Разберём, как проверить сайт за 30 минут бесплатными инструментами.

## Зачем проверять сайт

Регулярная проверка нужна, чтобы:

- не терять трафик из-за технических ошибок;
- вовремя замечать проблемы с безопасностью;
- понимать, что мешает росту позиций;
- не платить за SEO, если сайт «болен».

Проверять стоит раз в 1–3 месяца, а также после редизайна, переезда или смены хостинга.

## Проверка 1. Доступность и безопасность

### HTTPS

Откройте сайт — в адресной строке должен быть замок и `https://`. Если нет — срочно ставьте SSL-сертификат. Без него поиск понижает сайт, а браузеры показывают «не защищено».

### Ошибки сервера

Проверьте несколько страниц:
- главная;
- страница услуги;
- статья в блоге;
- контакты.

Если где-то 404 или 500 — это проблема.

### Вредоносный код

Проверьте сайт через:
- **Яндекс.Вебмастер** → «Безопасность»;
- **Google Search Console** → «Безопасность»;
- **VirusTotal** — загрузите URL.

Если поиск показывает «сайт может угрожать безопасности» — трафик упадёт мгновенно. Чинить срочно.

## Проверка 2. Индексация

### Сколько страниц в индексе

Введите в поиске: `site:вашсайт.ru`. Сравните число с реальным количеством страниц.

- Меньше — часть страниц не индексируется.
- Больше — в индексе мусор (теги, фильтры, дубли).

### Вебмастер и Search Console

Зайдите в оба сервиса:
- **«Диагностика»** — проблемы;
- **«Страницы в поиске»** — что в индексе, что исключено;
- **«Ошибки»** — 404, 5xx, редиректы.

### Robots.txt и sitemap

- **Robots.txt** — проверьте через «Проверку robots.txt» в Вебмастере. Не закрыты ли важные разделы?
- **Sitemap.xml** — есть ли он и добавлен ли в оба поисковика?

## Проверка 3. Скорость загрузки

### PageSpeed Insights

Откройте [pagespeed.web.dev](https://pagespeed.web.dev), введите URL. Смотрите:

| Метрика | Норма |
|---|---|
| LCP (Largest Contentful Paint) | до 2,5 с |
| CLS (Cumulative Layout Shift) | до 0,1 |
| INP (Interaction to Next Paint) | до 200 мс |

Если показатели хуже — сайт теряет позиции и пользователей.

### Что чинить в первую очередь

- сжать изображения (WebP);
- включить кэширование;
- убрать лишние скрипты;
- подключить CDN;
- проверить хостинг.

## Проверка 4. Мобильная версия

- Откройте сайт на телефоне.
- Читается ли текст без зума?
- Удобны ли кнопки?
- Нет ли горизонтальной прокрутки?
- Не перекрывает ли контент реклама?

Google ранжирует по мобильной версии — это критично.

## Проверка 5. SEO-элементы

### Метатеги

Проверьте на ключевых страницах:
- **Title** — уникальный, с ключом, до 60 символов. См. [[Title страницы: формула идеального заголовка]].
- **Description** — уникальный, до 160 символов. См. [[Meta description: как писать описания для SEO]].
- **H1** — один, с ключом.

### Дубли и canonical

- Открываются ли страницы по разным адресам (`site.ru` и `site.ru/index.html`)?
- Настроен ли `canonical`?
- Нет ли одинаковых title на разных страницах?

### Структура

- Логична ли навигация?
- Работает ли перелинковка?
- Есть ли «страницы-сироты» без входящих ссылок?

## Проверка 6. Контент

- Соответствует ли страница запросу?
- Полный ли ответ?
- Нет ли переспама (плотность выше 3–4%)?
- Нет ли дублей текста?

Подробнее — в [[SEO-текст]].

## Чек-лист проверки сайта

- [ ] HTTPS работает
- [ ] Нет ошибок 404 и 500
- [ ] Нет вредоносного кода
- [ ] Сайт в индексе (Вебмастер, Search Console)
- [ ] Robots.txt не закрывает важное
- [ ] Sitemap.xml добавлен
- [ ] LCP до 2,5 с
- [ ] CLS до 0,1
- [ ] Мобильная версия удобна
- [ ] Title уникальные
- [ ] Description заполнены
- [ ] H1 один на страницу
- [ ] Нет дублей
- [ ] Перелинковка работает

## Бесплатные инструменты

| Задача | Инструмент |
|---|---|
| Скорость | PageSpeed Insights |
| Индексация | Яндекс.Вебмастер, Google Search Console |
| Безопасность | VirusTotal, Вебмастер |
| Технический краулинг | Screaming Frog (до 500 URL) |
| Позиции | Topvisor (базово) |

## Что делать после проверки

1. **Составьте список проблем.** Разделите на критичные и второстепенные.
2. **Начните с критичных.** Безопасность, индексация, скорость.
3. **Проверьте результат** через 2–4 недели.
4. **Повторяйте проверку** раз в 1–3 месяца.

Подробнее о полном аудите — в [[SEO-аудит сайта]].

Проверка сайта — это быстрый способ увидеть, что мешает ему расти. Начните с безопасности и индексации, затем — скорость и мобильная версия, после — SEO-элементы и контент. Большинство проблем чинится бесплатно. А если хотите глубокий разбор — читайте [[SEO-аудит сайта]].
